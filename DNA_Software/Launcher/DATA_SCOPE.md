# Data scope

Import inspection distinguishes genotype arrays, sequence reads, alignments, variant calls, reference blocks, ancestry segments, Y-STR tables, GEDCOM and reports.

The source register shows detected format, build, measured versus imputed evidence, callable markers and missing prerequisites. File size and provider branding do not prove sequencing scope or quality.

A VCF does not establish whole-genome coverage. FASTQ filenames do not verify valid reads or mate pairing. Missing Y markers do not establish XX. An uploaded report does not become raw genetic evidence.

Analysis eligibility follows the selected tool's format, reference and quality requirements. Smaller measured arrays may support specific loci; clinical conclusions require independent confirmation.
