# DNA comparisons

Local comparisons operate on registered profiles and imported segment or genotype evidence. Available views include one-to-one, one-to-many, shared matches, chromosome segments, overlap matrices, clustering and genealogy searches.

The suite does not query commercial matching databases. Marker agreement is not shared-DNA percentage. Segment overlap is a candidate relationship, not verified triangulation. Relationship estimates can fit several pedigrees.

Use consistent reference builds and documented segment methods. Preserve source identity, thresholds and input fingerprints with each result. Hypothetical relatives have no fabricated measured DNA.
