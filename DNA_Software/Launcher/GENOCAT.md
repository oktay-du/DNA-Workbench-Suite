# GenoCAT and project image gallery

Source: [GenoCAT](https://github.com/hms-dbmi/genocat), confirmed by [HIDIVE Lab](https://hidivelab.org/research/projects/genocat/). Catalog code MIT, see `Notices/GENOCAT-LICENSE.txt`. Pinned commit `5f9f718c5312264688ae44e89ce6d73be6735ac6`, metadata dated 2022-10-06, retrieved 2026-11-04. The original genocat.tools site was unavailable during verification.

There are 107 tool records in this snapshot, each with a referenced image. The gallery also includes the suite's reviewed visualization adapters, including ones absent from the historical snapshot. On the current platform, tools with a reviewed installation recipe that are still missing appear first, followed by installed tools and discovery entries. Search covers names, formats, access and layout. Discovery entries link to their upstream project. Only reviewed suite recipes can trigger installation.

The existing plugin pages and tool library also show screenshots/example output published by upstream projects where registered. Thirteen of the forty curated projects supplied suitable README images; the others show a clear absence notice or CLI label rather than an invented interface. GenoCAT reproductions are labelled as such, with their historical date; they are not mislabelled current manufacturer screenshots. A displayed plot may be example output rather than application chrome.

Images are fetched on demand, size-limited, raster-validated and downscaled into `DNA_Software/UserData/Launcher/ToolMedia`, relative to the EXE root. They are not bundled into public source or profile backups. A catalog software license does not establish the redistribution license of every screenshot. Individual program licenses and current maintenance must still be checked before use.

CLI/MCP: `tools.catalog`, `tools.media_index`, `tools.picture`; GUI: GenoCAT & tool gallery, Plugins & sources, Tool library. Public image downloads contain no profile data. No personal DNA is uploaded to catalog websites.
