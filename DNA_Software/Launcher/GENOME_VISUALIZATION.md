# Genome visualisation

The tool gallery provides project links, versions, licences and supported launch adapters. IGV and JBrowse display alignments and variants; GenomeSpy and supported Python renderers provide complementary views.

Select compatible files from the active profile. Indexed alignment or variant views may require sidecars and an exact reference. Optional modules install on demand; a catalogue entry is not evidence of a successful installation.

Reference assemblies, browser tracks and generated plots remain source-labelled. Large sequencing data stay outside the public repository.
