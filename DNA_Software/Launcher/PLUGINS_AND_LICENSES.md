# Plugins and licences

Optional tools retain their upstream licences. Installation recipes identify project URLs, pinned versions, download sources and prerequisites. A plugin adapter does not bypass licence or redistribution restrictions.

The suite's MIT licence covers its own code. Third-party binaries, datasets, models and artwork have separate terms. Review the project notices and source links before distributing a packaged module.

Source download, installation and successful runtime verification are distinct states. Unsupported catalogue entries remain discovery links.
