# Profiles and exports

Profiles have persistent random identifiers, editable personal details, evidence sources, findings and results. Family links can include documented maternal and paternal paths and untested relatives.

Profile export includes the files and metadata needed for import elsewhere. Restoring an older state requires review; names do not identify profile identity.

Creative tools include a sequence-based educational helix, evidence-labelled heritage storybooks and photo-avatar design prompts. They do not reconstruct a face or infer migration routes without supporting results.
