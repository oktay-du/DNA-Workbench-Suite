# Profile preparation pipeline

1. Explicitly import files and review profile, provider, build and measurement assignments.
2. Analyse registered sources and run compatible quality checks.
3. Compare supported observed positions, retain conflicts and document excluded inputs.
4. Use the BestDataset action to publish a versioned preferred selection.

Reference-build conversion is not read realignment. SNP liftover requires a matching chain and target reference. Raw reads and alignments retain their own requirements and provenance.

Renewal is user-triggered. A failed generation preserves the previous version. Family relationships and manually entered profile information are retained.
