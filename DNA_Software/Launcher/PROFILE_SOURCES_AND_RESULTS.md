# Profile sources and saved results

Tools use the globally selected profile. Best choice selects compatible registered inputs; provider/version groups allow explicit source selection. Multi-profile analyses expose separate roles.

Saved results are keyed by tool, parameters and input fingerprints. Reuse available outputs or explicitly rerun after inputs change. File views and exports preserve source, date and tool metadata.

Reports, local analyses and self-reported information remain distinct evidence. The assistant can cite each source; conflicting claims remain visible.
