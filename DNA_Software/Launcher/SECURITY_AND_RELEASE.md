# Security and releases

The suite is source-available research software with MIT legacy material. It does not promise protection against reverse engineering. Release checksums detect accidental changes; they are not publisher signatures.

Build from the reviewed source checkout. Publish only source, synthetic samples and reviewed release assets. Exclude personal DNA, reports, profiles, credentials, reference datasets and runtime caches.

Report vulnerabilities through the repository's private reporting channel. See SECURITY.md and RELEASING.md for the supported process.
