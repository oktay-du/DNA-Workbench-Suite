# Sequence tools

Supported operations include FASTA/FASTQ statistics, interval extraction, reverse complement, translation and FASTA collection export. Use the tool-specific format contract to select compatible inputs.

Sequence concatenation creates a collection; it does not create a reconciled personal genome. A reference FASTA is not an individual's measured sequence. FASTQ quality checks and mate pairing are separate from variant interpretation.

Adapters use pinned upstream tools where applicable. Licence and version details are available in the tool gallery and THIRD_PARTY.md.

The Sequence lab adds a streaming VCF accounting audit, six-frame translation, ambiguity-aware motif search, model-input readiness, educational DNA message encoding and local agent handoffs. See [the research guide](../../docs/RESEARCH_LAB.md). These operations retain source receipts and are registered for GUI, CLI, JSON and MCP access.
