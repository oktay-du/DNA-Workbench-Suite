# DNA Workbench Suite

**Version 1.0.2 · Windows und Linux x64 · Lokale Genomforschung · Von OD**

Eine Anwendung für Windows und Linux: DNA-Quelldateien, Familienprofile, Forschungswerkzeuge und wiederverwendbare Ergebnisse. Englischer Anwendungskern mit deutscher Übersetzung sowie hellem und dunklem Design.

[Download](https://github.com/oktay-du/DNA-Workbench-Suite/releases/latest) · [Englische Dokumentation](README.md) · [Website](https://oktay-du.github.io/DNA-Workbench-Suite/)

## Anforderungen

| | Windows x64 | Linux x64 |
|---|---|---|
| Paket | [DNAWorkbench-Windows-x64.zip](https://github.com/oktay-du/DNA-Workbench-Suite/releases/latest/download/DNAWorkbench-Windows-x64.zip) | [DNAWorkbench-Linux-x64.zip](https://github.com/oktay-du/DNA-Workbench-Suite/releases/latest/download/DNAWorkbench-Linux-x64.zip) |
| Start | `DNA_Launcher.exe` | `./DNA-Workbench.sh` |
| Desktop | .NET Framework 4.8 und WebView2 | Python 3.12, GTK 3 und WebKitGTK 4.1 |
| Linux-Programme | laufen in WSL | laufen direkt auf dem Host |

Nach dem Entpacken unter Windows `DNA_Launcher.exe` starten und Core einrichten. Unter Linux `./DNA-Workbench.sh` starten. Mit den künstlichen Beispieldaten beginnen. Optionale Module werden bei Bedarf installiert. WSL ist nur unter Windows nötig und kann Administratorrechte und einen Neustart brauchen. Windows-only-Installer wie Gramps, JBrowse Desktop und UGENE haben keine Linux-Datei im Katalog. Wine wird nicht verwendet. [Welche Programme auf welchem System laufen](docs/VERSIONS.md).

Forschungssoftware, kein klinisches Diagnosesystem. Quelldaten und Ergebnisse bleiben standardmäßig lokal. Optionale externe Dienste haben eigene Datenschutz- und Lizenzbedingungen.
