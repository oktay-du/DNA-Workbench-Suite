# DNA Workbench Suite

**Version 1.0 · Windows x64 · Lokale Genomforschung · Von OD**

Eine Windows-Anwendung für DNA-Quelldateien, Familienprofile, Forschungswerkzeuge und wiederverwendbare Ergebnisse. Englischer Anwendungskern mit deutscher Übersetzung sowie hellem und dunklem Design.

[Download](https://github.com/oktay-du/DNA-Workbench-Suite/releases/latest) · [Englische Dokumentation](README.md) · [Website](https://oktay-du.github.io/DNA-Workbench-Suite/)

Nach dem Entpacken `DNA_Launcher.exe` starten, Core einrichten und mit den künstlichen Beispieldaten beginnen. Optionale Module werden bei Bedarf installiert. WSL benötigt entsprechende Windows-Unterstützung.

Forschungssoftware, kein klinisches Diagnosesystem. Quelldaten und Ergebnisse bleiben standardmäßig lokal. Optionale externe Dienste haben eigene Datenschutz- und Lizenzbedingungen.
