# Synthetic sample data

These are entirely artificial fixtures, not personal DNA, real ancestry results, clinical examples or a validated human reference. MIT licensed as part of DNA Workbench.

Use the app’s Sample data page or `DNA.cmd call sample.create` to add four clearly labelled demo profiles. Loading is explicit and does not replace existing people. The loader copies tiny sample files into local archives; packaged samples stay available.

The 12,000-base reference is synthetic. Do not label it GRCh37/38, use it for human liftover, or interpret its artificial rs-identifiers clinically. Quality values and ancestry percentages are authored fixtures. The map and segment tables illustrate imported results; they are not derived from these genotype files. Missing WGS, Y/mtDNA and health evidence stays missing.

VCF, chip TXT, FASTA, FASTQ/gzip, SAM, BED, CSV, JSON and GEDCOM are included. BAM/CRAM and indices may be included when regenerated with SAMtools. Do not add real files to this public folder.
