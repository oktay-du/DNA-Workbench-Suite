# Validation

Automated synthetic tests run on GitHub-hosted Windows runners. The release workflow builds the Windows executable and verifies packaging. See [Actions](https://github.com/oktay-du/DNA-Workbench-Suite/actions).

Tests cover imports, source provenance, archive handling, format contracts, profile transfer, cached jobs and generated outputs. Native tool checks use small synthetic fixtures. Screenshots use artificial profiles.

This research alpha is not clinically validated. Optional third-party tools, reference panels, real-world datasets and clean-PC setup require independent validation. Passing software tests does not establish medical or ancestry accuracy.
