# DNA Workbench Suite

## Τι μπορείτε να κάνετε

- Εισαγάγετε αρχεία DNA, φακέλους και υποστηριζόμενα αρχεία. Ελέγξτε τον πάροχο, τη μορφή και την έκδοση αναφοράς προτού αντιγράψετε ή μετακινήσετε οτιδήποτε.
- Ομαδοποιήστε σύνολα δεδομένων, έγγραφα και αποτελέσματα κατά προφίλ. Καταγράψτε την προέλευση κάθε αρχείου. Διατηρήστε τις άμεσες μετρήσεις ξεχωριστές από τις συναγόμενες τιμές και σημειώστε πότε έχουν εκχωρηθεί παραλλαγές σε αντίγραφα χρωμοσωμάτων.
- Ελέγξτε την ποιότητα του δείγματος και συγκρίνετε τις πηγές. Δημιουργήστε μια έκδοση BestDataset για ροές εργασίας που μπορούν να χρησιμοποιούν την ίδια έκδοση αναφοράς.
- Εξερευνήστε παραλλαγές και αρχεία αλληλουχίας με προγράμματα προβολής γονιδιώματος. Συγκρίνετε προφίλ DNA και συνδέστε τις σημειώσεις έρευνας με οικογενειακά αρχεία και αρχεία GEDCOM.
- Αποθηκεύστε τα αποτελέσματα με τις εισαγωγές και τα αρχεία καταγραφής τους. Εξαγωγή αναφορών και δημιουργία αντιγράφων ασφαλείας προφίλ για μελλοντική χρήση.
- Χρησιμοποιήστε τον προαιρετικό τοπικό βοηθό για πλοήγηση στο χώρο εργασίας. Μπορείτε να διαμορφώσετε το εξωτερικό AI ξεχωριστά.

## Εργαλεία και τι κάνουν

Αυτά είναι επιλεγμένα εργαλεία που η σουίτα ενσωματώνει ή μπορεί να ξεκινήσει. Η διαθεσιμότητα ποικίλλει ανάλογα με τη ροή εργασίας και το λειτουργικό σύστημα. Ορισμένες λειτουργικές μονάδες και δεδομένα αναφοράς είναι ξεχωριστές λήψεις.

| Εργαλείο | Τι κάνει |
| --- | --- |
| [SAMtools](https://www.htslib.org/) | Διαβάζει, ευρετηριάζει και επιθεωρεί στοιχισμένα αρχεία αλληλουχίας σε μορφές SAM, BAM και CRAM. |
| [BCFtools](https://samtools.github.io/bcftools/) | Φιλτράρει, κανονικοποιεί, συνδυάζει και επιθεωρεί αρχεία παραλλαγών σε μορφές VCF και BCF. |
| [fastp](https://github.com/OpenGene/fastp) | Ελέγχει την ποιότητα ανάγνωσης του FASTQ και μπορεί να περικόψει ή να φιλτράρει τις αναγνώσεις. |
| [mosdepth](https://github.com/brentp/mosdepth) | Μετρά την κάλυψη ανάγνωσης από αρχεία BAM και CRAM. |
| [MultiQC](https://seqera.io/multiqc/) | Συνδυάζει αναφορές από πολλαπλά εργαλεία ποιοτικού ελέγχου σε μία προβολή. |
| [PLINK](https://www.cog-genomics.org/plink/2.0/) | Λειτουργεί με δεδομένα γονότυπου για εργασίες όπως φιλτράρισμα παραλλαγών, συνάφεια και ανάλυση κύριου συστατικού. |
| [Beagle](https://faculty.washington.edu/browning/beagle/beagle.html) | Χρησιμοποιεί δεδομένα γονότυπου για να συμπεράνει ποιες παραλλαγές βρίσκονται στο ίδιο αντίγραφο ενός χρωμοσώματος. |
| [hap-ibd](https://github.com/browning-lab/hap-ibd) | Βρίσκει αντίστοιχα τμήματα DNA που κληρονομήθηκαν από έναν κοινό πρόγονο. Χρησιμοποιεί δεδομένα γονότυπου με παραλλαγές που έχουν εκχωρηθεί σε αντίγραφα χρωμοσωμάτων. |
| [WhatsHap](https://github.com/whatshap/whatshap) | Χρησιμοποιεί αναγνώσεις αλληλουχίας για να εκχωρήσει παραλλαγές σε αντίγραφα χρωμοσωμάτων. |
| [Truvari](https://github.com/ACEnglish/truvari) | Συγκρίνει δομικές παραλλαγές σε αρχεία VCF. |
| [IGV](https://igv.org/doc/desktop/) | Εμφανίζει ευθυγραμμισμένες αναγνώσεις, παραλλαγές και άλλα κομμάτια γονιδιώματος σε συγκεκριμένες τοποθεσίες. |
| [JBrowse](https://jbrowse.org/jb2/) | Σας επιτρέπει να περιηγείστε διαδραστικά σε ακολουθίες αναφοράς και συνδεδεμένα κομμάτια. |
| [GenomeSpy](https://genomespy.app/) | Αποδίδει διαδραστικούς γονιδιωματικούς χάρτες με επιτάχυνση γραφικών του προγράμματος περιήγησης. |
| [Gramps](https://www.gramps-project.org/) | Οργανώνει γενεαλογικά αρχεία, οικογενειακά δέντρα και δεδομένα GEDCOM. |
| [OpenCRAVAT](https://docs.opencravat.org/en/latest/Home.html) | Σημειώνει παραλλαγές χρησιμοποιώντας επιλέξιμες πηγές και σχολιαστές. |
| [Ensembl VEP](https://www.ensembl.org/info/docs/tools/vep/index.html) | Προβλέπει πώς οι παραλλαγές μπορεί να επηρεάσουν τα γονίδια, τις μεταγραφές και τις πρωτεΐνες. |
| [PharmCAT](https://pharmcat.org/) | Παράγει αναφορές φαρμακογενετικής έρευνας από υποστηριζόμενες εισροές γονότυπου. |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | Εκτελεί το προαιρετικό μοντέλο τοπικής γλώσσας σε συμβατούς χρόνους εκτέλεσης CPU και GPU. |

## Ξεκινήστε

Επιλέξτε το πακέτο που ταιριάζει με το λειτουργικό σύστημα και τον επεξεργαστή σας. Η σελίδα έκδοσης παραθέτει τις λήψεις x64 και ARM64 για Windows, Linux και macOS. Ορισμένες εκδόσεις είναι προεπισκοπήσεις.

1. Στο Windows, εξαγάγετε το αρχείο και εκτελέστε το πρόγραμμα εκκίνησης. Ολοκληρώστε τη ρύθμιση Core όταν σας ζητηθεί.
2. Στο Linux, ξεκινήστε τον εκκινητή κελύφους που περιλαμβάνεται με εγκατεστημένα τα Python, GTK και WebKitGTK.
3. Στο macOS, κρατήστε την εφαρμογή δίπλα στα αρχεία του χώρου εργασίας που έχουν εξαχθεί. Η προεπισκόπηση απαιτεί macOS 13 ή νεότερη έκδοση και Python 3.12 ή μεταγενέστερη έκδοση.
4. Ξεκινήστε με τα συνθετικά δείγματα που περιλαμβάνονται για να δοκιμάσετε τις ροές εργασίας χωρίς να χρησιμοποιήσετε προσωπικά αρχεία.

## Γραμμή εντολών και αυτοματισμός

Χρησιμοποιήστε το ίδιο μητρώο εντολών μέσω της διεπαφής επιφάνειας εργασίας, CLI, JSON-RPC και MCP. Η υπηρεσία χωρίς κεφάλι λειτουργεί στο τοπικό μηχάνημα. Μπορείτε να παραθέσετε εντολές και να διαβάσετε τα σχήματά τους χωρίς να ανοίξετε ένα παράθυρο επιφάνειας εργασίας.

```text
python DNA_Software/Launcher/dna_cli.py commands
python DNA_Software/Launcher/dna_cli.py serve
```

Ο προαιρετικός βοηθός μπορεί να σας βοηθήσει να πλοηγηθείτε στα αποτελέσματα. Οι απαντήσεις του δεν αντικαθιστούν τα δεδομένα πηγής ή μια επαληθευμένη ανάλυση.

> Ερευνητικό λογισμικό. Τα αποτελέσματα εξαρτώνται από την είσοδο, τη μέθοδο και τις αναφορές. Το DNA Workbench Suite δεν παρέχει κλινική διάγνωση.
