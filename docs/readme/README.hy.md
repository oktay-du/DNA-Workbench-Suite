## Ինչ կարող ես անել

- Ներմուծեք ԴՆԹ ֆայլեր, թղթապանակներ և աջակցվող արխիվներ: Նախքան որևէ բան պատճենելը կամ տեղափոխելը վերանայեք մատակարարին, ձևաչափին և տեղեկանքի կառուցվածքը:
- Խմբավորել տվյալների հավաքածուները, փաստաթղթերը և արդյունքներն ըստ պրոֆիլի: Գրանցեք յուրաքանչյուր ֆայլի ծագումը: Պահպանեք ուղղակի չափումները ենթադրյալ արժեքներից և նշեք, երբ տարբերակները վերագրվել են քրոմոսոմային պատճեններին:
- Ստուգեք նմուշի որակը և համեմատեք աղբյուրները: Կառուցեք տարբերակված BestDataset աշխատանքային հոսքերի համար, որոնք կարող են օգտագործել նույն հղման կառուցվածքը:
- Ուսումնասիրեք տարբերակները և ֆայլերի հաջորդականությունը գենոմի դիտողների հետ: Համեմատեք ԴՆԹ-ի պրոֆիլները և միացրեք հետազոտական ​​նշումները ընտանեկան գրառումների և GEDCOM ֆայլերի հետ:
- Պահպանեք արդյունքները իրենց մուտքերով և տեղեկամատյաններով: Արտահանեք հաշվետվություններ և կրկնօրինակեք պրոֆիլները՝ հետագա օգտագործման համար:
- Աշխատանքային տարածքում նավարկելու համար օգտագործեք ընտրովի տեղական օգնականը: Դուք կարող եք առանձին կարգավորել արտաքին AI-ն:

[Ամբողջական հնարավորությունների կատալոգ](../FEATURES.md) · [Աջակցվող ձևաչափեր](../TOOL_FORMATS.md)

## Գործիքներ և այն, ինչ նրանք անում են

Սրանք ընտրված գործիքներ են, որոնք փաթեթը ինտեգրում է կամ կարող է գործարկել: Հասանելիությունը տատանվում է ըստ աշխատանքային հոսքի և օպերացիոն համակարգի: Որոշ մոդուլներ և տեղեկատու տվյալներ առանձին ներբեռնումներ են:

| [BCFtools](https://samtools.github.io/bcftools/) | Զտում, նորմալացնում, միավորում և ստուգում է տարբերակված ֆայլերը VCF և BCF ձևաչափերով: |
| [fastp](https://github.com/OpenGene/fastp) | Ստուգում է FASTQ ընթերցման որակը և կարող է կրճատել կամ զտել ընթերցումները: |
| [mosdepth](https://github.com/brentp/mosdepth) | Չափում է ընթերցման ծածկույթը BAM և CRAM ֆայլերից: |

| [hap-ibd](https://github.com/browning-lab/hap-ibd) | Գտնում է ընդհանուր նախահայրից ժառանգած ԴՆԹ-ի համապատասխան հատվածները: Այն օգտագործում է գենոտիպային տվյալներ՝ քրոմոսոմների պատճեններին վերագրված տարբերակներով: |

## Սկսեք

Ընտրեք փաթեթը, որը համապատասխանում է ձեր օպերացիոն համակարգին և պրոցեսորին: Թողարկման էջը թվարկում է x64 և ARM64 ներբեռնումները Windows, Linux և macOS-ի համար: Որոշ կառուցումներ նախադիտումներ են:

1. Windows-ում հանեք արխիվը և գործարկեք գործարկիչը: Լրացրեք Core կարգավորումը, երբ հուշում է:
2. Linux-ում գործարկեք ներառված կեղևի գործարկիչը՝ տեղադրված Python, GTK և WebKitGTK:
3. macOS-ում պահեք հավելվածը արդյունահանված աշխատանքային տարածքի ֆայլերի կողքին: Նախադիտման համար պահանջվում է macOS 13 կամ ավելի նոր տարբերակ և Python 3.12 կամ ավելի նոր տարբերակ:
4. Սկսեք ներառված սինթետիկ նմուշներից՝ փորձելու աշխատանքային հոսքերը՝ առանց անձնական ֆայլերի օգտագործման:

[Բեռնել](https://github.com/oktay-du/DNA-Workbench-Suite/releases/latest) · [Տեղադրման ուղեցույց](../GETTING_STARTED.md)

## Հրամանի տող և ավտոմատացում

Օգտագործեք նույն հրամանի ռեեստրը աշխատասեղանի միջերեսի միջոցով՝ CLI, JSON-RPC և MCP: Անգլուխ ծառայությունն աշխատում է տեղական մեքենայի վրա։ Դուք կարող եք ցուցակագրել հրամանները և կարդալ դրանց սխեմաները՝ առանց աշխատասեղանի պատուհան բացելու:

```text
python DNA_Software/Launcher/dna_cli.py commands
python DNA_Software/Launcher/dna_cli.py serve
```

Լրացուցիչ օգնականը կարող է օգնել ձեզ նավարկելու արդյունքները: Դրա պատասխանները չեն փոխարինում աղբյուրի տվյալներին կամ ստուգված վերլուծությանը:

> Հետազոտական ​​ծրագրեր. Արդյունքները կախված են մուտքագրումից, մեթոդից և հղումներից: DNA Workbench Suite-ը կլինիկական ախտորոշում չի տալիս:
