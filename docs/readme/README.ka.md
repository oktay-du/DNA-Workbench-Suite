## რაც შეგიძლია გააკეთო

- დნმ ფაილების, საქაღალდეების და მხარდაჭერილი არქივების იმპორტი. გადახედეთ პროვაიდერს, ფორმატს და მითითების კონსტრუქციას, სანამ რაიმეს დააკოპირებთ ან გადაიტანთ.
- ჯგუფური მონაცემთა ნაკრები, დოკუმენტები და შედეგები პროფილის მიხედვით. ჩაწერეთ თითოეული ფაილის წარმოშობა. შეინახეთ პირდაპირი გაზომვები განცალკევებული დასკვნის მქონე მნიშვნელობებისგან და გაითვალისწინეთ, როდის მიენიჭა ვარიანტები ქრომოსომის ასლებს.
- შეამოწმეთ ნიმუშის ხარისხი და შეადარეთ წყაროები. შექმენით ვერსიირებული BestDataset სამუშაო პროცესებისთვის, რომლებსაც შეუძლიათ გამოიყენონ იგივე მითითების კონსტრუქცია.
- გამოიკვლიეთ ვარიანტები და ფაილების თანმიმდევრობა გენომის მნახველებით. შეადარეთ დნმ-ის პროფილები და დააკავშირეთ კვლევის ჩანაწერები ოჯახის ჩანაწერებთან და GEDCOM ფაილებთან.
- შეინახეთ შედეგები მათი შეყვანით და ჟურნალებით. ანგარიშების ექსპორტი და პროფილების სარეზერვო ასლის შექმნა შემდგომი გამოყენებისთვის.
- გამოიყენეთ არასავალდებულო ადგილობრივი ასისტენტი სამუშაო სივრცეში ნავიგაციისთვის. თქვენ შეგიძლიათ ცალკე დააკონფიგურიროთ გარე AI.

## დაიწყეთ

აირჩიეთ პაკეტი, რომელიც შეესაბამება თქვენს ოპერაციულ სისტემას და პროცესორს. გამოშვების გვერდზე ჩამოთვლილია x64 და ARM64 ჩამოტვირთვები Windows, Linux და macOS. ზოგიერთი ნაგებობა არის გადახედვა.

1. Windows-ზე ამოიღეთ არქივი და გაუშვით გამშვები. დაასრულეთ Core დაყენება მოთხოვნისას.
2. Linux-ზე გაუშვით ჭურვის გამშვები დაინსტალირებული Python, GTK და WebKitGTK.
3. macOS-ზე შეინახეთ აპი ამოღებული სამუშაო სივრცის ფაილებთან. გადახედვისთვის საჭიროა macOS 13 ან უფრო ახალი და Python 3.12 ან უფრო ახალი.
4. დაიწყეთ თანდართული სინთეტიკური ნიმუშებით, რათა სცადოთ სამუშაო ნაკადები პირადი ფაილების გამოყენების გარეშე.

## ბრძანების ხაზი და ავტომატიზაცია

გამოიყენეთ იგივე ბრძანების რეესტრი დესკტოპის ინტერფეისის საშუალებით, CLI, JSON-RPC და MCP. უთავო სერვისი მუშაობს ადგილობრივ მანქანაზე. თქვენ შეგიძლიათ ჩამოთვალოთ ბრძანებები და წაიკითხოთ მათი სქემები დესკტოპის ფანჯრის გახსნის გარეშე.

```text
python DNA_Software/Launcher/dna_cli.py commands
python DNA_Software/Launcher/dna_cli.py serve
```

არჩევითი ასისტენტი დაგეხმარებათ შედეგების ნავიგაციაში. მისი პასუხები არ ცვლის წყაროს მონაცემებს ან დამოწმებულ ანალიზს.

> კვლევის პროგრამული უზრუნველყოფა. შედეგები დამოკიდებულია შეყვანაზე, მეთოდსა და მითითებაზე. DNA Workbench Suite არ იძლევა კლინიკურ დიაგნოზს.
