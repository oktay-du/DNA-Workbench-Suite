# DNA Workbench Suite

**ДНХ файл, гэр бүлийн бүртгэл, судалгааны ажлын урсгалыг нэг орон нутгийн ажлын талбарт.**

Эх сурвалжаа хүн болон үйлчилгээ үзүүлэгчээр нь цэгцэлж, тохирох файлуудыг харьцуулж, дүн шинжилгээ бүрийн ард оролт, үр дүнг хадгалаарай.

## Та юу хийж чадах вэ

- ДНХ файл, хавтас болон дэмжигдсэн архивыг импортлох. Ямар нэгэн зүйлийг хуулах, зөөхөөс өмнө үйлчилгээ үзүүлэгч, формат, лавлагааны бүтэцтэй танилцана уу.
- Мэдээллийн багц, баримт бичиг, үр дүнг профайлаар бүлэглэх. Файл бүрийн гарал үүслийг тэмдэглэ. Шууд хэмжилтийг таамагласан утгуудаас тусад нь байлгаж, хромосомын хуулбаруудад хувилбарууд хуваарилагдсаныг тэмдэглэ.
- Дээжийн чанарыг шалгаж, эх сурвалжийг харьцуулна уу. Ижил лавлагааны бүтцийг ашиглаж болох ажлын урсгалд зориулсан хувилбартай BestDataset-г бүтээгээрэй.
- Геном үзэгчдийн тусламжтайгаар хувилбарууд болон дарааллын файлуудыг судлаарай. ДНХ-ийн профайлыг харьцуулж, судалгааны тэмдэглэлийг гэр бүлийн бүртгэл болон GEDCOM файлуудтай холбоно уу.
- Үр дүнг тэдгээрийн оролт, бүртгэлээр хадгал. Тайлан экспортлох, дараа нь ашиглахын тулд профайлаа нөөцлөх.
- Ажлын талбарт шилжихийн тулд нэмэлт орон нутгийн туслахыг ашиглана уу. Та гадаад AI-г тусад нь тохируулах боломжтой.

## Багаж хэрэгсэл ба тэд юу хийдэг

Эдгээр нь багцад нэгтгэсэн эсвэл эхлүүлэх боломжтой сонгосон хэрэгслүүд юм. Боломжит байдал нь ажлын урсгал болон үйлдлийн системээс хамаарч өөр өөр байдаг. Зарим модуль болон лавлагааны өгөгдөл нь тусдаа татан авалт юм.

| Хэрэгсэл | Юу хийдэг вэ |
| --- | --- |
| [SAMtools](https://www.htslib.org/) | SAM, BAM болон CRAM форматаар зэрэгцүүлсэн дарааллын файлуудыг уншиж, индексжүүлж, шалгана. |
| [BCFtools](https://samtools.github.io/bcftools/) | VCF болон BCF форматтай хувилбар файлуудыг шүүж, хэвийн болгож, нэгтгэж, шалгана. |
| [fastp](https://github.com/OpenGene/fastp) | FASTQ уншилтын чанарыг шалгадаг бөгөөд уншилтыг тайрч, шүүх боломжтой. |
| [mosdepth](https://github.com/brentp/mosdepth) | BAM болон CRAM файлуудаас унших хамрах хүрээг хэмждэг. |
| [MultiQC](https://seqera.io/multiqc/) | Чанарын хяналтын олон хэрэглүүрийн тайлангуудыг нэг харагдац болгон нэгтгэдэг. |
| [PLINK](https://www.cog-genomics.org/plink/2.0/) | Хувилбар шүүх, хамаарал, үндсэн бүрэлдэхүүн хэсгүүдийн шинжилгээ зэрэг ажлуудад генотипийн өгөгдөлтэй ажилладаг. |
| [Beagle](https://faculty.washington.edu/browning/beagle/beagle.html) | Хромосомын ижил хуулбар дээр аль хувилбарууд байгааг тогтоохын тулд генотипийн өгөгдлийг ашигладаг. |
| [hap-ibd](https://github.com/browning-lab/hap-ibd) | Нийтлэг өвөг дээдсээс өвлөн авсан тохирох ДНХ сегментүүдийг олно. Энэ нь хромосомын хуулбаруудад хуваарилагдсан хувилбаруудтай генотипийн өгөгдлийг ашигладаг. |
| [WhatsHap](https://github.com/whatshap/whatshap) | Хромосомын хуулбаруудад хувилбаруудыг хуваарилахын тулд дарааллын уншлагыг ашигладаг. |
| [Truvari](https://github.com/ACEnglish/truvari) | VCF файлуудын бүтцийн хувилбаруудыг харьцуулна. |
| [IGV](https://igv.org/doc/desktop/) | Тодорхой байршилд зэрэгцүүлсэн уншилт, хувилбарууд болон бусад геномын замуудыг харуулна. |
| [JBrowse](https://jbrowse.org/jb2/) | Лавлах дараалал болон холбогдсон замуудыг интерактив байдлаар үзэх боломжийг танд олгоно. |
| [GenomeSpy](https://genomespy.app/) | Интерактив геномын диаграммыг хөтчийн график хурдатгалтай дүрсэлдэг. |
| [Gramps](https://www.gramps-project.org/) | Удам угсаа, ургийн мод, GEDCOM өгөгдлийг зохион байгуулдаг. |
| [OpenCRAVAT](https://docs.opencravat.org/en/latest/Home.html) | Сонгох боломжтой эх сурвалж болон тэмдэглэгээг ашиглан хувилбаруудыг тэмдэглэнэ. |
| [Ensembl VEP](https://www.ensembl.org/info/docs/tools/vep/index.html) | Хувилбарууд ген, транскрипт, уурагт хэрхэн нөлөөлж болохыг урьдчилан таамаглаж байна. |
| [PharmCAT](https://pharmcat.org/) | Дэмжигдсэн генотипийн орцуудаас фармакогенетикийн судалгааны тайлан гаргадаг. |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | Тохиромжтой CPU болон GPU ажиллах цаг дээр нэмэлт орон нутгийн хэлний загварыг ажиллуулдаг. |

## Эхлээрэй

Өөрийн үйлдлийн систем болон процессортой тохирох багцыг сонгоно уу. Хувилбарын хуудсанд Windows, Linux болон macOS-д зориулсан x64 болон ARM64 татан авалтуудыг жагсаав. Зарим бүтээцийг урьдчилан харах боломжтой.

1. Windows дээр архивыг задлаад эхлүүлэгчийг ажиллуул. Сануулахад үндсэн тохиргоог дуусгана уу.
2. Linux дээр Python, GTK болон WebKitGTK суулгасан бүрхүүл эхлүүлэгчийг эхлүүлнэ үү.
3. macOS дээр програмыг задалсан ажлын файлуудын хажууд байлга. Урьдчилан үзэхэд macOS 13 буюу түүнээс дээш хувилбар, Python 3.12 буюу түүнээс дээш хувилбар шаардлагатай.
4. Хувийн файл ашиглахгүйгээр ажлын урсгалыг туршиж үзэхийн тулд нийлэг дээжээс эхэл.

## Тушаалын мөр ба автоматжуулалт

CLI, JSON-RPC болон MCP ширээний интерфейсээр дамжуулан ижил тушаалын бүртгэлийг ашиглана уу. Толгойгүй үйлчилгээ нь орон нутгийн машин дээр ажилладаг. Та ширээний цонх нээхгүйгээр командуудыг жагсааж, схемүүдийг нь уншиж болно.

```text
python DNA_Software/Launcher/dna_cli.py commands
python DNA_Software/Launcher/dna_cli.py serve
```

Нэмэлт туслах нь үр дүнг удирдахад тань тусална. Түүний хариултууд нь эх сурвалж мэдээлэл эсвэл баталгаажуулсан дүн шинжилгээг орлохгүй.

> Судалгааны програм хангамж. Үр дүн нь оролт, арга, лавлагаа зэргээс хамаарна. DNA Workbench Suite нь эмнэлзүйн оношийг өгдөггүй.
