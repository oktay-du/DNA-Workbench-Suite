## Maxaad samayn kartaa

- Soo rar faylasha DNA, galalka iyo kaydadka la taageeray. Dib u eeg bixiyaha, qaabka iyo dhisidda tixraaca ka hor intaadan koobin ama guurin wax.
- Xog ururinta, dukumentiyada iyo natiijooyinka profile ahaan. Qor feyl kasta asalkiisa. Ka ilaali cabbirada tooska ah inay ka duwan yihiin qiyamka la qiyaasi karo oo fiirso marka kala duwanaanshiyaha lagu meeleeyay koobiyada koromosoomyada.
- Hubi tayada muunada oo is barbar dhig ilaha. U dhis BestDataset nooca loo qaabeeyey socodka shaqada kaasoo isticmaali kara isla tixraaca dhismo.
- Ku baadh noocyada iyo faylasha isku xigxiga leh daawadayaasha genome. Is barbar dhig xogta DNA-ga oo ku xidh qoraallada cilmi-baadhista diiwaannada qoyska iyo faylasha GEDCOM.
- Ku keydi natiijooyinka gelitaankooda iyo diiwaanadooda Dhoofinta warbixinada oo ku celi profiles si hadhow loo isticmaalo.
- Isticmaal kaaliyaha deegaanka ee ikhtiyaarka ah si aad ugu dhex socoto goobta shaqada. Waxaad si gooni gooni ah u habeyn kartaa AI dibadda.

## Qalabka iyo waxa ay qabtaan

Kuwani waa qalab la doortay oo qolku isku xidho ama bilaabi karo. Helitaanka ayaa ku kala duwan socodka shaqada iyo nidaamka hawlgalka. Qaybaha qaar iyo xogta tixraacu waa soodejin gaar ah.

| Qalab | Waxa ay qabato |
| --- | --- |
| [SAMtools](https://www.htslib.org/) | Wuxuu akhriyaa, tusiyaa oo kormeeraa faylalka isku xigxiga ee isku xiga ee qaababka SAM, BAM iyo CRAM. |
| [BCFtools](https://samtools.github.io/bcftools/) | Shaandheeya, caadiyeeyaa, isku daraa oo baadhaa faylalka kala duwan ee qaababka VCF iyo BCF. |
| [fastp](https://github.com/OpenGene/fastp) | Waxay hubisaa tayada akhrinta FASTQ oo gooyn kartaa ama shaandhayn kartaa akhrinta. |
| [mosdepth](https://github.com/brentp/mosdepth) | Tallaabooyinka akhrinta caymiska ee faylasha BAM iyo CRAM. |
| [MultiQC](https://seqera.io/multiqc/) | Isku-dubarid warbixinnada laga helayo agabyo badan oo lagu xakameynayo tayada hal aragti. |
| [PLINK](https://www.cog-genomics.org/plink/2.0/) | La shaqeeya xogta genotype ee hawlaha sida kala duwanaanshiyaha shaandhaynta, xidhiidhka iyo falanqaynta qaybta aasaasiga ah. |
| [Beagle](https://faculty.washington.edu/browning/beagle/beagle.html) | Wuxuu adeegsadaa xogta genotype si uu u ogaado kala duwanaanshiyaha ku jira nuqul la mid ah koromosoomyada. |
| [hap-ibd](https://github.com/browning-lab/hap-ibd) | Hela qaybaha DNA-da ee is-waafaqaya ee laga dhaxlay awoowe wadaag ah. Waxay isticmaashaa xogta genotype oo leh noocyo loo qoondeeyay nuqullada koromosoomyada. |
| [WhatsHap](https://github.com/whatshap/whatshap) | Wuxuu adeegsadaa akhrinta isku xigxiga si uu u kala duwanaado koobiyada koromosoomyada. |
| [Truvari](https://github.com/ACEnglish/truvari) | Is barbar dhig kala duwanaanshiyaha qaabdhismeedka ee faylasha VCF. |
| [IGV](https://igv.org/doc/desktop/) | Wuxuu muujiyaa akhrinta toosan, kala duwanaanshiyaha iyo raadadka genome-ga kale ee meelo gaar ah. |
| [JBrowse](https://jbrowse.org/jb2/) | Waxa uu kuu ogolaanayaa inaad si dhexgal ah u baadho taxanaha tixraaca iyo raadadka ku xidhan. |
| [GenomeSpy](https://genomespy.app/) | Waxay soo saartaa jaantusyo genomic is-dhexgal leh oo leh dardargelinta sawirada browserka. |
| [Gramps](https://www.gramps-project.org/) | Waxay abaabushaa diiwaanka abtirsiinta, geedaha qoyska iyo xogta GEDCOM. |
| [OpenCRAVAT](https://docs.opencravat.org/en/latest/Home.html) | Wuxuu qeexayaa kala duwanaanshiyaha isagoo isticmaalaya ilo la dooran karo iyo annotators. |
| [Ensembl VEP](https://www.ensembl.org/info/docs/tools/vep/index.html) | Wuxuu saadaaliyaa sida kala duwanaanshuhu u saameyn karaan hiddo-wadaha, qoraallada iyo borotiinada. |
| [PharmCAT](https://pharmcat.org/) | Waxay soo saartaa warbixinnada cilmi-baarista farmashiyaha ee laga helo gelitaanka genotype ee la taageeray. |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | Ku shaqeeya qaabka luqadda maxaliga ah ee ikhtiyaarka ah ee ku habboon CPU iyo GPU runtimes. |

## Bilow

Dooro xirmada ku habboon nidaamkaaga hawlgalka iyo processor-ka. Bogga siideynta waxaa ku taxan x64 iyo ARM64 la soo dejiyey ee Windows, Linux iyo macOS. Dhismayaasha qaar waa horudhac.

1. On Windows, soo saar kaydka oo socodsii furaha Dhamaystir dejinta Core marka la soo jeediyo.
2. Marka la joogo Linux, ku billow soosaaraha qolofka lagu soo daray ee Python, GTK iyo WebKitGTK lagu rakibay.
3. Markay tahay macOS, ku hay abka agtiisa faylalka goobta shaqada ee la soo saaray. Horudhacku wuxuu u baahan yahay macOS 13 ama wixii ka dambeeya iyo Python 3.12 ama wixii ka dambeeya.
4. Ka bilow shaybaarada synthetic ee ku jira si aad isugu daydo socodka shaqada adiga oo aan isticmaalin faylasha gaarka ah.

## Line Command iyo Automation

Isticmaal isla diiwaanka amarka adoo adeegsanaya interface interface, CLI, JSON-RPC iyo MCP. Adeegga madax la'aanta wuxuu ku shaqeeyaa mishiinka deegaanka. Waxaad qori kartaa amarrada oo aad akhrin kartaa qorshahooda adiga oo aan furin daaqada miiska.

```text
python DNA_Software/Launcher/dna_cli.py commands
python DNA_Software/Launcher/dna_cli.py serve
```

Kaaliyaha ikhtiyaariga ah ayaa kaa caawin kara inaad maareyso natiijooyinka. Jawaabaheedu ma beddelaan xogta isha ama falanqaynta la xaqiijiyay.

> Software-ka cilmi-baarista. Natiijadu waxay ku xidhan tahay gelinta, habka iyo tixraacyada. DNA Workbench Suite ma bixiso baadhitaan caafimaad.
