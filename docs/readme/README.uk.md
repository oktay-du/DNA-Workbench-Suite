# DNA Workbench Suite

**Файли ДНК, сімейні записи та дослідницькі робочі процеси в одній локальній робочій області.**

[Завантажити](https://github.com/oktay-du/DNA-Workbench-Suite/releases/latest) · [Веб-сайт](https://oktay-du.github.io/DNA-Workbench-Suite/?lang=uk) · [Керівництво по установці](../GETTING_STARTED.md) · [Переклади](#translations)

## Що ви можете зробити

- Імпорт файлів ДНК, папок і підтримуваних архівів. Перш ніж копіювати або переміщувати будь-що, перевірте постачальника, формат і еталонну збірку.
- Групуйте набори даних, документи та результати за профілем. Запишіть походження кожного файлу. Зберігайте прямі вимірювання окремо від прогнозованих значень і відзначайте, коли варіанти були призначені копіям хромосом.
- Перевірте якість зразка та порівняйте джерела. Створіть версійований BestDataset для робочих процесів, які можуть використовувати ту саму еталонну збірку.
- Досліджуйте варіанти та файли послідовностей за допомогою засобів перегляду геному. Порівняйте профілі ДНК і зв’яжіть нотатки дослідження з сімейними записами та файлами GEDCOM.
- Зберігайте результати з їх введеннями та журналами. Експортуйте звіти та створюйте резервні копії профілів для подальшого використання.
- Використовуйте додаткового локального помічника для навігації робочим простором. Ви можете налаштувати зовнішній AI окремо.

## Інструменти та те, що вони роблять

Це вибрані інструменти, які пакет інтегрує або може запускати. Доступність залежить від робочого процесу та операційної системи. Деякі модулі та довідкові дані завантажуються окремо.

| Інструмент | Що воно робить |
| --- | --- |
| [SAMtools](https://www.htslib.org/) | Читає, індексує та перевіряє вирівняні файли секвенування у форматах SAM, BAM і CRAM. |
| [BCFtools](https://samtools.github.io/bcftools/) | Фільтрує, нормалізує, об’єднує та перевіряє файли варіантів у форматах VCF і BCF. |
| [fastp](https://github.com/OpenGene/fastp) | Перевіряє якість читання FASTQ і може обрізати або фільтрувати читання. |
| [mosdepth](https://github.com/brentp/mosdepth) | Вимірює покриття читання з файлів BAM і CRAM. |
| [MultiQC](https://seqera.io/multiqc/) | Об’єднує звіти з кількох інструментів контролю якості в одне подання. |
| [PLINK](https://www.cog-genomics.org/plink/2.0/) | Працює з даними генотипу для таких завдань, як фільтрація варіантів, спорідненість і аналіз головних компонентів. |
| [Beagle](https://faculty.washington.edu/browning/beagle/beagle.html) | Використовує дані генотипу, щоб визначити, які варіанти лежать на тій самій копії хромосоми. |
| [hap-ibd](https://github.com/browning-lab/hap-ibd) | Знаходить відповідні сегменти ДНК, успадковані від спільного предка. Він використовує дані генотипу з варіантами, присвоєними копіям хромосом. |
| [WhatsHap](https://github.com/whatshap/whatshap) | Використовує зчитування послідовності для призначення варіантів копіям хромосом. |
| [Truvari](https://github.com/ACEnglish/truvari) | Порівнює структурні варіанти у файлах VCF. |
| [IGV](https://igv.org/doc/desktop/) | Відображає вирівняні зчитування, варіанти та інші треки генома в певних місцях. |
| [JBrowse](https://jbrowse.org/jb2/) | Дозволяє інтерактивно переглядати еталонні послідовності та пов’язані треки. |
| [GenomeSpy](https://genomespy.app/) | Відтворює інтерактивні геномні діаграми з прискоренням графіки браузера. |
| [Gramps](https://www.gramps-project.org/) | Упорядковує генеалогічні записи, сімейні дерева та дані GEDCOM. |
| [OpenCRAVAT](https://docs.opencravat.org/en/latest/Home.html) | Анотує варіанти за допомогою вибраних джерел і анотаторів. |
| [Ensembl VEP](https://www.ensembl.org/info/docs/tools/vep/index.html) | Прогнозує, як варіанти можуть впливати на гени, транскрипти та білки. |
| [PharmCAT](https://pharmcat.org/) | Виготовляє звіти про фармакогенетичні дослідження на основі підтримуваних даних генотипу. |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | Запускає необов’язкову локальну мовну модель на сумісному CPU та GPU. |

## Почніть роботу

Виберіть пакет, який відповідає вашій операційній системі та процесору. На сторінці випуску перелічено завантаження x64 і ARM64 для Windows, Linux і macOS. Деякі збірки є попередніми переглядами.

1. На Windows розпакуйте архів і запустіть програму запуску. Завершіть налаштування ядра, коли буде запропоновано.
2. На Linux запустіть включену програму запуску оболонки з установленими Python, GTK і WebKitGTK.
3. На macOS зберігайте програму поруч із витягнутими файлами робочої області. Для попереднього перегляду потрібен macOS 13 або новішої версії та Python 3.12 або новішої версії.
4. Почніть із включених синтетичних зразків, щоб спробувати робочі процеси без використання особистих файлів.

## Командний рядок і автоматизація

Використовуйте той самий реєстр команд через інтерфейс робочого столу, CLI, JSON-RPC і MCP. Безголовий сервіс працює на локальній машині. Ви можете перераховувати команди та читати їхні схеми, не відкриваючи вікно робочого столу.

```text
python DNA_Software/Launcher/dna_cli.py commands
python DNA_Software/Launcher/dna_cli.py serve
```

Додатковий помічник може допомогти вам орієнтуватися в результатах. Його відповіді не замінюють вихідних даних чи перевіреного аналізу.

> Дослідницьке програмне забезпечення. Результати залежать від вхідних даних, методу та посилань. DNA Workbench Suite не дає клінічного діагнозу.
