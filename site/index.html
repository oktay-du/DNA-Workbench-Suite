Requirements

Windows x64

Extract DNAWorkbench-Windows-x64.zip and run DNA_Launcher.exe. The host needs .NET Framework 4.8. Core setup downloads portable Python and WebView2. Linux programs such as samtools run inside WSL, which can require administrator access and a restart.

Linux x64

Extract DNAWorkbench-Linux-x64.zip and run ./DNA-Workbench.sh. The host supplies Python 3.12, GTK 3 and WebKitGTK 4.1. The same Linux programs run on this host. WSL is not used, and Windows-only installers are not started through Wine.

Start with a sample. Keep control of your data.

On Windows, extract the package, run DNA_Launcher.exe and complete Core setup. On Linux, extract the package and run ./DNA-Workbench.sh. Artificial sample profiles are included. Personal DNA and large references are not included in the repository.

Local processing is the default. Optional cloud AI and external services have separate data flows and policies.

Developers can use the same typed commands through GUI, CLI, JSON and MCP. English is the source language, with German localization and light/dark themes.
