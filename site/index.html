Pick the architecture that matches your system. Available packages and verification status are listed in the release notes.

Windows

Extract the ZIP and open DNA_Launcher.exe. The ARM64 preview requires Windows 11 and WebView2 Evergreen.

Linux

Run ./DNA-Workbench.sh with Python 3.12, GTK 3 and WebKitGTK 4.1 installed.

The preview uses a native WebKit window. It requires macOS 13 or later and Python 3.12 or later.
